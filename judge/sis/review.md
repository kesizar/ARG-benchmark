# SIS 数据准备与验收

本条对应 `base664:0012`。已有本地镜像共 27 个文件，约 22.5 MB；来源为公开的 `miumiu660/SIS` 仓库。当前固定版本按所有文件 SHA-256 识别，不声称是最新上游版本。

## 环境与资源

这是完整本地化的“模拟互联网调查”游戏。页面里显示的机构域名、邮箱和登录界面都由同一个本地 React 程序渲染，不是真实外部网站或真实账号。运行层级为 L1。游戏账户验证是谜题的一部分，不能误分类为需要用户提供账号的外部条件。

游戏资源包与独立评测包分开。资源包只包含 `tasks/sis/mirror/`；评测包含配置、共享 harness、裁判和 UI 验收脚本。浏览器每局使用全新 context；“清空进度”UI 也另有测试。运行目录、程序异常、HTTP 资源错误和白名单拦截均纳入验收。

## 原作缺陷与最小兼容修改

发现原作的状态更新助手用闭包中的旧 React 状态计算新状态。同一个点击事件内“写发现或登录标记，再切换页面”会发生后一次更新覆盖前一次，导致线索笔记、已访问网页和登录标记丢失。

只将一个更新助手改为 React 函数式状态更新，并持久化实际合并后的状态。没有改变答案、账号、搜索条件、结局触发条件或题目文案。原始 JS 保存在 `source/07b4973k49z5k.original.js`。与旧资源包比较，只有该应用脚本发生变动；所有其他游戏资源保持原样。精确原始哈希和变更在 `tasks/sis/provenance.json`。

## 全流程与覆盖边界

可操作流程为：标题页 → 初始邮件 → 捐赠证明 → 模拟搜索与网页调查 → 虚构员工登录 → 虚构管理员登录 → 完整档案与福利院检索 → 邮件云盘解密 → 五题确认 → 叙事邀请 → 普通或完美结局。

实际程序不强制玩家先完成全部调查：知道答案时可以直接从邮件解密云盘，提交最终问答并到达任一结局。因此普通阅读和三项调查验证不能全部列为每条结局的必经门。本次同时验证完整调查路径和跳过调查的短路径。

具体覆盖包括 11 个搜索结果页（包括原作故意设置的“损坏网页”）、模拟机构网站的六个页签、员工后台四个页签、管理员后台四个页签、完整档案、福利院正误查询、文件、笔记与两种结局。故意损坏的虚构网页是叙事内容，不是本地资源 HTTP 404。

源码还保留 intro/desktop 两个旧渲染分支，但当前“开始”按钮直接进入邮件，没有可操作入口进入这两个状态；它们在 `flow.json` 中明确列为不可达旧状态，不冒称实机经过。

“普通结局”和“完美结局”是原作的明确标签，分别映射 normal 和 good；两者都算正式完成。无额外死亡或失败终止结局。错误登录、查询、解密和问答均允许重试。

## 判分点

共九个点：

- 可选调查点三项：员工密码验证、管理员密码验证、福利院指定人物或编号检索。实际成功页面/结果作证据，不依赖可能被旧程序丢失的标记。
- 必经点六项：云盘密码验证，以及五道最终推理问答。

普通阅读、点击附件、打开文件、查看记录、搜索命中页面、普通叙事选择均记事件或覆盖信息，不因点击数量增加主分。

原作只提供最终问答全对后的一个聚合标记。为逐题判分，裁判在页面上安装只读提交监听器：只有玩家实际提交最终表单后，才读取五项已选答案并按独立规则判断；选择后未提交不加分，错误的单题不加分，提交部分正确可获得对应题目进度。监听器不改变游戏状态、表单选择、页面反馈或推进条件。被测模型看不到裁判表达式和记录。每个点由裁判锁存；原作结局前删除部分存档标记不会导致已得分消失。

## 验收证据

`verify_sample.py` 通过 `BrowserHarness.act` 执行真实点击和输入。它不注入游戏状态，不调用内部导航、登录或结局函数。源码只用于裁判侧建立验收路径，不作为模型题面。

验证从新上下文开始零分；完整调查和短路径分别到达两种结局。完整路线对错误账号、已作废账号、错误密码、错误福利院查询、错误云盘密码和全错最终问答检查不误加分，再逐题修正并提交，检查五道题依次增加分数。还验证完成后回首页、继续、取消重开、确认清空全部进度与永久通关标记。

权威结果在 `verification/acceptance.json`，独立目录重新部署结果在 `deployment.json` 指向的解压目录。只有这些文件明确通过后才能认定相应阶段通过。验收脚本成绩不是模型成绩，本次未调用付费模型 API。独立目录测试使用本机已有 Python 包和浏览器，不等于全新操作系统安装验收。

## 仍需注意

游戏中的员工和管理员验证是本地虚构身份，不适合拿来证明真实账号登录通路可用。存在已知答案短路径，必须保留其可绕过性质；不能为了提高进度分母而人为补上程序不存在的强制步骤。读题难度和正式收录质量仍需单独复核。
