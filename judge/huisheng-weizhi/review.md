# 裁判与路线核查

冻结版本来源及资源哈希见 data/preparation/results/base664-0452-crawl.json。源码检索见 scripts/huisheng-weizhi/inputs-audit.txt、echo-structure.txt；源码和材料不向模型托管。

真实受验证的输入：江渡大学学号（学生证，校媒中查询）；回声昵称及白榆桥拼音（原作虚构账户）；公司站 E7 查询显示拦截并给出“回声不会忘记”；帮助中心 RETAINED 输入该句恢复三份历史记录；回声账号搜索 NULL 打开其资料触发本机消息；本机文档私人备忘 NULL 解锁；系统设置隐藏数据 `linmudechengguo` 解锁。搜索站点常见词/普通阅读本身不计分；E7 权限提示是可继续的线索而不是终局失败。读取 NULL.txt、交还证据作为诊断而非推理得分。裁判按操作后即时状态锁存；各项可跳过，不强加在每条路线。

交还需先触发 NULL、阅读 NULL.txt 并向木棉发送完整证据，进入转交页面后还需点“看看后来发生了什么”才显示 ENDING 01。END 02/03/04/05 对应全部证据、去除我、仅栖川、全部删除；每条都存在 ENDING 卡片和通向最终确认的按钮，尽管内容价值不同，没有作机制上的终局失败。所有结局按 normal 处理以免把叙事负面和程序失败混为一谈。最终确认前3题不校验且空/错可继续；第四题自由输入，不能将这些题算作正确判断。

原作任何人知道私密密码即可绕过所有此前调查直接选结局，交还路线也可绕过学号和历史数据等；路由 gates 仅保留真正执行的输入门，不暗称所有材料必经。用户可直接访问已知 URL 是风险，配置禁止模型 goto；仍需正式复核评分设计、难度和材料前提。

五路每次从入口用独立新浏览器上下文正常 UI 达到结局、最终确认及 full-story，输入正负及具体记录见 verification/acceptance.json、acceptance-truth.json 和 acceptance-handback.json。前四条复用只新增与它们无关的 E7 hook 和交还判定的后来版本；truth 补测 E7，handback 补测延迟显示。浏览器默认 context 的新局即重置；未验证其他操作系统或真实模型解题表现。结局页面中的畸形额外属性经点击可正常进入最终确认，无需修复。
