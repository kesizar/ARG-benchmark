# 观测档 A / B / C

主测默认 B。同一题可以各跑一档，报告按 `obs_mode` 分列，不合成一个分数。

| 档 | 给模型的内容 | 点击 |
|---|---|---|
| A | 可见文字、元素编号、标签页、地址（若开启）、对话框、上一步结果、预算 | 只用元素编号 `n` |
| B | A 的内容再加视口截图 | 编号优先，也允许坐标 |
| C | 视口截图、标签页、对话框、上一步结果、预算。没有可见文字，没有元素表 | 只用坐标 `x,y` |

A 档可以在 `runs/` 里留截图文件，但不会放进给模型的观察。

`computer_use` 默认关闭。打开它也不会增加桌面控制，只表示这道题允许走坐标点击。

可见文字会丢掉脚本、样式、隐藏节点、移出页面左侧的节点、小于 4px 的字，以及几乎被裁成 1–2px 的溢出隐藏块。不读取 HTML 注释、属性、localStorage 或网络响应。
