# 路线的阈值前置条件

部分作品允许任意完成一组题中的若干题后进入终局。每个谜题仍独立判分；路线不应展开成大量人造组合。

裁判路线的 `gates` 表示固定必经点，`gate_groups` 表示互不重叠的阈值组，例如 `{"ids":["sort1","sort2","sort3"],"required":2}`。组内命中达到2个后，该组路线进度即满，不强迫完成第3个；额外命中仍保留在独立checkpoint记录，不使路线进度超过1。

固定门与各组按所需点数相加，组内贡献为 `min(命中数, required)`。原有可选门的结局前后处理不变。组成员必须为critical checkpoint，不能与固定门或其他组重复；不合法阈值在读取裁判时拒绝。结局仍由真实终局钩子证明，不因满足阈值自动伪造结局。

当前用于《疑案卷宗》的任意10/12排序与首级证据择一条件；不把198种题目组合写成198条不同游戏路线。该扩展不改变不含gate_groups的历史裁判含义。
